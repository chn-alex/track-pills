# Telegram-бот для відміток прийому таблеток

PHP 7.4+, MySQL та Telegram Bot API.

## Можливості
- кнопки для відмітки прийому кожної таблетки за сьогодні;
- повторне натискання скасовує відмітку;
- налаштовуваний список таблеток;
- календар-історія за місяць із переходом між місяцями;
- окремі дані для кожного Telegram-користувача;
- часова зона `Europe/Kyiv`.

## Встановлення
1. Створити бота через `@BotFather` у Telegram та отримати токен.
2. Створити MySQL-базу на хостингу.
3. Імпортувати `schema.sql` через phpMyAdmin.
4. Скопіювати `config.php.example` у `config.php` і вписати токен та доступи до БД.

## Команди
- `/start` — запуск; створить дві початкові позиції «Таблетка 1» і «Таблетка 2».
- `/add Назва таблетки` — додати таблетку.
- `/delete ID` — прибрати таблетку зі списку (історія зберігається).
- `/tablets` — показати список з ID.
- `/calendar` — календар поточного місяця.
- `/calendar 2026-09` — календар конкретного місяця.
